# v0.10.0 · 松仓工作台融合

保留 React、Ant Design 和现有统一操作抽屉，引入暖纸底色、陶土强调、商品分组、关注事项、单件档案与家庭动态。Web 与 MCP App 共用实现。

- 默认按商品浏览，展开后辨认独立实物；支持位置、日期和不分组视图。商品及实物分别分页，跨页选择保留，并明确显示隐藏选择和实际操作范围。
- 日期已过、未来 14 天、余量不足和借出等关注筛选组合使用；日期采用家庭时区，未知时区与余量保持未知，同款实物的百分比不相加。
- 单件档案展示位置、明确记录的生命周期和余量，连接消耗、整件用完、移动、资料、笔记与历史；移动端打开和关闭档案时管理键盘焦点。
- 家庭动态按操作组织，按需加载完整操作记录，并可进入关联对象。
- 入库优先呈现商品、件数和位置，可选详情展开；日期依据不再预设。保留现有草稿、版本检查、幂等、原子写入与分类审批协议。
- 共享快照补充家庭时区；没有新增数据库 migration，没有改变既有实物身份或库存数据。

设计依据见 [融合方案](stash-integration-plan.md)、[产品约束](../PRODUCT.md) 和 [视觉规范](../DESIGN.md)。

## 验证

本地 Node 24 隔离环境已通过类型检查、Web/MCP 构建、124 项单元及集成测试、52 项 Chromium 测试、18 项发布要求的 WebKit 测试，另有 2 项新增工作台 WebKit 回归；36 张表的合成数据库备份恢复一致。覆盖多实例分页、隐藏选择、操作历史、未知值、响应式尺寸和焦点往返。

正式发布仍由 GitHub Actions 对提交执行完整 CI、15 项发布控制器测试和真实容器迁移／恢复，再构建镜像并部署。生产状态以对应 Release 记录及 `/health` 的版本和提交为准。

真实 iPhone 和真实 ChatGPT/Codex 宿主的输入法、composer、旋转、安全区及辅助技术仍需实机验收；浏览器模拟不替代真实宿主结论。所有写入测试使用隔离合成库存。

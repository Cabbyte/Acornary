# 发布与恢复 runbook（设计，未执行）

## 迁移器先行

独立迁移连接池/会话锁跨事务持有，不能继承业务 15s statement/idle timeout。登记 name、checksum、transactional、status、attempt、step、checkpoint、错误代码。步骤 STARTED/APPLIED/FAILED 可核对；失败恢复依据数据库对象状态，不仅依据进程退出码。历史摘要与既有部署控制器 schema.json/release 清单核对；没有可靠摘要登记 UNVERIFIED，需人工签署，不能把当前文件 hash 冒充历史证据。006 缺号说明历史原因，不补造 migration。

普通 SQL 每文件事务；并发索引一文件一步非事务。失败后验证本任务索引定义及 indisvalid，只清理匹配且 invalid 的索引。已经有效但尚未登记的索引先核验再补记，不能无条件 DROP/CREATE。大回填独立可恢复任务，按家庭/keyset 分批，记录源水位，限制批次耗时和资源。

## 三段发布

Expand：先加兼容结构和桥接代码，先捕获日志后建新投影；后台回填/并发索引/VALIDATE，影子读比对。每批主线可部署，新语义默认关闭。独立开关包括新读模型、同步、模板新写、全屋语义、附件；最低协议最后从 1 翻到 2。

Switch 前：完成全量副本审计与 oracle 比对、约束验证、资源/性能门禁、最近在线备份和恢复演练。Android 桥接版已安装验证，升级不清理 pending operations/打印记录；插件能识别旧 bundle。不能通过无限保留旧写接口绕过客户端准备。

短窗口：阻止新写→排空事务→取得最终家庭水位→小量追赶并核验已完成检查点→翻读写开关/最低版本→只读 smoke→恢复 v2 写。若仍需大回填/建索引则取消切换，恢复兼容服务，不把工作拖进窗口。

Contract：至少观察七天、全部证据通过后，单独移除旧端点/过渡代码/冗余索引；不删历史定义、事件或回执。权限可提前收紧已证明兼容的部分，其余在对应迁移后落实。

## 回退矩阵

| 状态 | 可执行恢复 |
|---|---|
| Online expand 失败、旧语义仍在运行 | 保持当前兼容服务，阻断后续切换；修复/重试当前步骤 |
| 新读模型失败、业务写仍兼容 | 关新读开关；继续捕获变化，不能回到不发日志的版本 |
| 已启用新版语义写入 | 只上兼容新数据的修复版本；不以旧数据库覆盖新写入 |
| 日志缺口/数据库恢复 | 换 sync_generation、作废同步/导出会话并重建 |
| 不确定是否提交 | 进入 needs_attention，保留数据/日志，不自动回滚 schema 或重放新幂等键 |

## NAS/SFTP 备份

每日 Asia/Shanghai 04:00；同一 PostgreSQL 导出快照生成 dump 与业务/文件 manifest，所有文件引用固定后复制 immutable blobs；备份期间持有 GC 租约。不能把持续写入的线上库与旧备份直接比较摘要。

restic 加密写入独立 NAS/SFTP，保留 7 日/4 周。部署必填：repository、受限 SFTP 凭据、独立保存的解密密钥、告警去向。密钥不进 Git/日志/唯一备份副本；另由操作者保管。认证恢复还需保存匹配的 Better Auth secret 和应用 digest。未配置异机目的地或无法独立取回密钥，备份门禁保持 NOT_RUN。

恢复在隔离数据库和独立文件目录中完成；校验备份时 manifest、每个附件 SHA-256、目标关联及旧回执；最后换同步代次。公开 health 仅报必要状态，受控诊断记录迁移/模板摘要、存储、积压、SQL 数/耗时、锁等待和最近成功备份时间。

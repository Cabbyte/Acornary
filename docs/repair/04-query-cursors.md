# 04 · 查询、游标和冻结导出

## 搜索与过滤

搜索字段统一为实物有效名称、SKU 名称/规格/品牌/型号/条码、物品 ID、位置路径、可搜索笔记。规范化顺序：NFKC → Unicode 小写 → 连续空白折成一个空格 → trim。服务端与客户端使用同一黄金样本，原始业务文字不改写。

中文短词使用规范化 Unicode code point 的一/二元候选集合（按单字段生成，不跨字段拼出候选）；GIN 找候选后做完整子串复核。较长文字使用 trigram。敏感和 SECRET 内容不进普通索引。日期/引用/数值过滤由 registry 声明允许操作符和类型；SQL 标识符只取白名单，值参数化。日期类型与范围必须匹配同一条日期记录。

基础库存默认排除作废，current 排除终态但含未知；容器展示和物资汇总分别定义，不能因为隐藏目录就排除实物。件数、未知数、同量纲余量分别计，不累加 percent。商品分组与明细共享匹配集合，分页不影响汇总。

## Browse

允许排序：created_at、updated_at、有效名称、最近可执行日期；默认 created_at DESC，所有排序追加同方向 id；空值最后。游标载荷包含 version、household、query_hash、sort、最后排序键、初始 as_of_change_id。游标不是权限凭证；每次重新鉴权。非法/跨家庭/条件不匹配游标返回 INVALID_CURSOR。

每页在一个 REPEATABLE READ READ ONLY 事务中取得数据、总计和当前家庭 H。`stale = H != initial_as_of`；保守地将无关家庭内变更也标 stale，但不阻止翻页。summary.as_of_change_id=H，不冒称整次 live 遍历是同一快照。相对日期在首个请求解析成家庭自然日边界并写入 query_hash，翻页中途不偷偷移动边界。

客户端按 ID 去重，保留显式选择，提示刷新；本轮可能漏掉插入或移动到游标之前的对象，这是浏览语义。写入仍按明确 ID 和最新 revision 校验，不以“全选某商品组”隐式扩大授权。

## Export

begin_export 在 REPEATABLE READ 中构建私有冻结结果集，记下家庭 H、调用者、query_hash、披露模式和生成代次；统计和内容同源。分页按 `(export_id, ordinal)`，不跨请求持有数据库事务。默认 TTL 一小时；继续读取时验证账号和家庭授权。

实时修改不改变冻结内容；过期、代次变化、查询/披露模式不一致返回 CURSOR_STALE。结果集不发库存 sync 事件；原文导出需要显式选择并记访问审计。下载能力使用受限票据，不给公开链接。

## 性能证据

生成器/seed/分布入库，数据集固定 10k Item、100k Event、10k Note，多家庭与深树。当前 ITEM 仅支持 lifecycle/contents/container 三种模板，不能伪造“五个合法 v1 绑定”作为基线；扩展模板后的五绑定样本在 Batch 4 补充。

与生产同资源限制运行，每个代表性查询预热 100 次、采样 1,000 次，三轮，分别记录单并发及五读一写。冷启动单独记录 30 次，注明 OS 页缓存是否清理。记录业务 SQL 数（目标 ≤5）及含鉴权/事务控制的总数。p95 目标：物品 ≤300ms，历史 ≤150ms，搜索 ≤200ms；写入下降 >10% 不自动豁免。保存 EXPLAIN ANALYZE/BUFFERS、数据摘要、版本及原始样本，不将小表 Seq Scan 一概判失败。

## 九个场景与自动化覆盖

| 文档场景 | 已验证的自动化边界 |
| --- | --- |
| 已有商品再次购买 | 无规范也能补货，复用商品，未知属性保持空 |
| 新商品进入已有分类 | 直接挂SKU，整批创建，不自动加深目录 |
| 规则内新增分类 | 允许的分支/深度原子扩展；受限子规则不可绕过 |
| 越界或冲突 | POLICY_REQUIRED/CLASSIFICATION_CONFLICT，具体一次性批准，失败无部分实体 |
| 同款异重、同位置 | 一SKU，两件不同重量；共同日期合并与完整位置路径 |
| 别名/不同表达 | 确认别名、NFKC/大小写/空白规范化；同名不直接复用，实质不同规格保留 |
| 发现旧目录问题 | 不自动治理；旧入口必须有精确确认；历史例外单独记录 |
| 响应丢失/并发 | 原键重试与回执相同；不同成员共享SKU、各自创建实物 |
| 批量某项失败 | 分类、SKU、Item、索引、事件、回执整批回滚 |

另外覆盖截断/空页计数、明确引用对象的完整依赖、条码候选、商品补充事实、位置祖先变化、规范变化、跨家庭既有鉴权、不同操作者的确认/回执隔离、伪造来源、确认过期、私有工具元数据，以及数据库运行权限。自然语言近义表达的语义稳定性不由这些结构测试证明。

## 目标与交付

装配需要留意、最近变化两页，并与已批准的浏览链路相连。正式页面源码位于 `apps/web/src/features/daily/pages/daily-attention.tsx`、`daily-activity.tsx`；读取状态容器增加可传入的加载文案。数据、规则示例和路由仍由 `review/pages/` 提供。RC6 组件与 Token 未改动。

- 留意默认日期，提供已过记录日、今天、未来 7 天；示例为明确 BEST_BEFORE 类型，保留包装依据，不称为使用期限风险。补货展示零库存 SKU、显式 1 件阈值与未知数量 0；借出和维护为无记录样例。未知事实不触发提醒。
- 最近变化按记录日分组，默认最近 7 天，可改 30 天；按发生时间倒序。示例包含同一物品三个独立操作和连续 revision，动态与单件历史共用同一数据。可展开变更、技术内容，进入物品历史并返回。
- 每页 9 种场景；分页场景每页 1 条，通常每页 50 条。只给正式页面传当前页数据和分页信息。离线总数未知，缓存范围明确。
- 两页意见使用独立稳定 ID 和 P02-RC1 版本；导航后意见跟随真实页面。没有写入伪造的审阅意见。

领域展示沿用 ItemView、GroupView、DateFactPresentation、HistoryEventV2。日期/策略/时区判定仅是隔离样例输入，真实服务端查询与授权不在本轮接通。

# 验收矩阵与可测量条件

本表定义未来验收，不把设计覆盖视为实现通过。P1=本轮规格检查，P2=隔离fixture中的生产组件，P3=隔离家庭真实协议，U=真人任务，H=真实宿主/设备。除“本轮验证”外均为未执行。

## 产品任务的测量口径

起点统一：已登录、正确家庭、目标页面首屏已可交互；不计登录时间，但单独记录。终点：用户看到实际回执或取得任务所需正确事实；不能以点击提交为完成。失败、放弃、需要协助都计入结果。

主要动作计数包括：打开任务、选定实体/位置/类型、改变步骤、确认执行。必要文字输入和数字输入不计入“主要动作”目标，但记入总点击/按键与耗时；展开选择器、选择位置、逐件编辑、审批、冲突核对、额外危险确认均记录，不为达标偷偷排除。一次触控/键盘激活计一次；双击视为两次输入并测试无重复执行。

至少5位使用者（尽量含日常使用者及整理者），在相同隔离数据/任务指令/设备上比较当前版与候选，顺序交叉平衡，记录每人的原始数据，不用小样本宣称统计显著。每任务目标：至少4/5独立完成；错误对象/跨家庭写入/重复提交/丢失未决请求为0；核心任务中位耗时不高于当前版。额外确认次数分别记必要业务确认和无信息重复确认，后者目标0。耗时无基线前不编造秒数改善。

## 性能基线与预算冻结方法

本轮没有新UI、未运行应用性能基准；性能数字为待测，不是PASS。先在独立main checkout和隔离家庭测B0，再给vNext定绝对预算，禁止先承诺没有来源的350KB/100ms等历史目标。B0是Phase 2任务内的测量工作，不是额外审计阶段。

固定数据：11 / 500 / 5000 Item，含10%未知量、同款多实例、20层最大测试路径（若领域上限更低则按实际合法上限）、长名称、异单位；不用正式库存。记录每组真实fixture数及生成规则。生产组件不直接import这些数据。

| 指标     | 测量起止与环境                                                                  |
| -------- | ------------------------------------------------------------------------------- |
| 首屏     | 冷缓存导航至首屏目标列表可操作；同时记LCP/网络/服务器耗时；Web/MCP分开          |
| 搜索     | compositionend/Enter至正确结果绘制；分别记录debounce、请求、渲染；30次热样本    |
| 列表渲染 | 首页、加载更多与5000数据范围的分页；不要求把5000一次加载DOM                     |
| 详情     | 点击已明确Item至关键事实可读；冷/热分别                                         |
| Sheet    | 点击入口至标题/首字段可操作；不把远程校验等待当纯动画时间                       |
| 筛选     | 应用筛选至正确第一页和summary；统计必须和query一致                              |
| 初始JS   | Web/plugin生产构建入口实际加载chunk的raw/gzip/brotli；分路由及认证/打印lazy依赖 |
| MCP差异  | 相同数据/网络、真实host版本、iframe尺寸、桥调用与重挂载耗时                     |

每项至少30个热样本、10个冷样本，报告p50/p95、错误/取消数、设备/浏览器/CPU/网络条件；失败样本不静默剔除。预算提议须填B0与理由：初步门槛为同环境p95不退化超过10%，超过即查明；绝对预算在B0后写入DEC-07并审核。模拟CPU/网络只证明模拟条件，真实手机另测。后端查询延迟与前端渲染分别报告。

## 工程命令及安全环境

main 根 package.json 当前有效命令：

```sh
pnpm typecheck
pnpm build
pnpm test
pnpm test:e2e
```

要求Node24（package.json >=24 <25），pnpm11.19.0。CI通过Docker browser-test与scripts/ci.mjs创建隔离PostgreSQL执行；本机无同等依赖时用既有隔离流程，不接生产.env。当前无pnpm lint脚本或ESLint依赖，不能声称运行过；Phase 2按现有Prettier并明确是否增加新UI ESLint规则，不凭空填写命令。不得删测/放宽断言/跳过失败功能宣布通过。

Phase 3若基底变为Cloudflare，重新读取目标package.json与CI运行其native/workerd、contract、browser和host命令；不能照搬main的PostgreSQL命令视为workerd通过。

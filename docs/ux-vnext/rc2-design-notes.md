# 松仓 · Acornary RC2 设计候选说明

本轮状态为 **Operate（操作优先）／候选**，范围仍是隔离预览中的 70 个组件和 5 个组合场景，全部待用户审阅。用户授权修正横向空间浪费、标题弱和文案冗余，不等于批准本轮视觉。已认可的 D01–D09、M01–M06 流程、四套浅色配色与日常／管理两种模式继续保留；`sage / daily` 仍只是预览初始值。

本文记录当前源码中已有的呈现方式，不作检查通过或视觉验收结论。限定检查结果、未验证项和交付边界由 [RC2 报告](rc2-report.md)记录；[RC1 报告](rc1-report.md)、[RC1 设计说明](rc1-design-notes.md)和[密度与文案审计](rc1-density-copy-audit.md)保留为历史依据。

## 默认画面与信息层级

默认先回答“是什么、在哪里、当前事实是什么、会影响什么、可以做什么”。完整编号、来源依据、版本、普通帮助和技术回执保留可访问入口，不在每一行重复展开。密度来自并排组织、删除重复标签与减少嵌套面板；长名称、错误和关键事实仍允许换行、增高。

| 已有调整 | 当前呈现与边界 |
| --- | --- |
| `ItemIdentity` | 名称使用前景色与 600 字重；日常为 16px，管理和表格内为 14px。常态去掉下划线，交互标题在 hover／焦点时显示下划线。摘要显示编号末 8 位，可展开完整 ID；打开、复制和选择仍使用完整 ID。 |
| `ItemRow`／`ItemCard` | 共享身份、位置、余量、日期和动作区域；宽容器按列排列，窄容器按任务顺序重排。状态与名称相邻，额外事实和阻断反馈继续可见。 |
| `ProductSummary`／`DataTable` | 商品事实按可用空间分栏。表格在主单元格提供带可读名称的展开入口，承载事实与记录详情；装配方可关闭重复的“打开”动作或重复选择摘要，隐藏选择和实际范围仍需由唯一摘要表达。 |
| `QuantityInput`／`DateFactField` | 数量、单位、依据并排；日期类型与日期输入组合排列。数量规则、来源依据等普通说明按需展开，移除重复读回；未记录、估计、类型和验证错误仍有明确表达。 |
| 搜索、筛选与表单组合 | 搜索使用可读但默认视觉隐藏的字段标签；有条件时显示筛选数量和条件，无条件时省略“未设置”提示。组合表单在足够宽时分两栏。 |
| 操作、历史与附件 | 操作卡片减少内边距，Sheet 内避免重复卡片边框；冲突选择和历史前后值可并排。附件使用分隔线组织列表，历史详情、审批版本及技术回执按需展开。 |

`FactDetails` 使用原生 `details / summary`，承载身份、日期及来源详情；日期摘要显示真实日期类型、日期和状态，依据与来源可展开。`FormField` 的普通帮助默认由带可读名称的帮助按钮展开，错误仍直接显示；必须常显的字段上下文可使用 `hintMode="visible"`。

## 短动作与图标

关闭、清空、日历、展开和扫码等成熟入口使用 Lucide 图标与可读名称；图标的视觉大小与点击区域分开。普通帮助通过点击或键盘展开，不能只依赖 hover。扫码能力不可用时，搜索旁的入口可以打开原因说明，不产生扫描成功的假象。

使用、移动、搜索、确认和恢复保留短文字。现有操作文案包括“设为未记录”“确认此范围”“确认选择”“核对原请求”“保留并离开”；审批或结果未知的动作不能缩成含义模糊的纯图标。“核对原请求”仍指向原任务，不表达重新提交。

## 不能折叠掉的事实

- 数量未记录与已知零不同；估计性质、数量依据和真实日期类型继续可见，十进制输入按原字符串保留。
- 摘要中的编号片段只帮助辨认，不替代完整实物 ID。同名物品仍结合位置、日期和身份澄清；操作核对使用明确对象。
- 缓存或已加载子集、权限不可见、禁用原因、跨页隐藏选择与批量影响范围保持明确；不把展示压缩变成全量或权限承诺。
- 审批的家庭、仅本次／长期规则、有效期、影响列表和无效性提示常显；提案 ID 与正常版本详情可以展开。批准不代表操作已经完成。
- 冲突的对象范围、原值、当前值、我的输入和选择常显；未知、不可见或资料不完整仍阻止确认。正常版本号可收进详情。
- 核对与提交中保留关闭守卫；结果未知显示恢复提示并保留原任务，身份／家庭变化继续隐藏旧任务内容。

## 按容器重排

下面是当前局部 CSS 的布局规则，不是新 Token 定义，也不是已完成的视口验收。

| 所在容器 | 当前规则 |
| --- | --- |
| 物品行 | 容器至少 800px 时按身份／位置／余量／日期／动作并排；较窄时为身份、位置、数量与日期、动作的多行结构。 |
| 组合画布 | 普通组合上限 720px，宽组合 1440px，表单组合 1120px；搜索工具在 800px 起并排，表单在 820px 起分两栏，管理布局在 960px 起显示 200px 树侧栏。 |
| 数量／日期字段 | 数量字段小于 440px 时将依据移到下一行；到期日期字段小于 400px 时转为单列。输入保持各自可用宽度。 |
| 冲突／历史／附件 | 冲突选择与历史前后值在容器至少 520px 时并排；附件在小于 480px 时将动作移到下一行。 |
| Shell／Sheet | Shell 容器小于 1024px 时切换为窄布局，示例 Shell 高度由内容撑开；审批与冲突默认使用宽 Sheet，窄容器继续使用全宽全高 Sheet。 |

窄容器与粗指针继续沿用触控尺度，帮助和展开入口保留足够点击区域。长文本与错误不为了固定行高而裁掉。1440×900 首屏普通列表约 5–6 件、390px 无水平滚动等审计目标仍需以本轮报告中的实际观察为准，本文不把目标写成结果。

## 预览、Token 与交付状态

工作台和 Storybook 共用 `ReviewFrame`：画布外统一显示“预览 · 示例数据”，演示边界和说明收进“审阅说明”；无事件时省略空点击日志，实际演示反馈仍显示。场景中的本地状态不代表库存、账号、审批或设备接线。

[source.json](../../apps/web/src/ui/tokens/source.json)仍是唯一可编辑 Token 值源。本轮不重写它或 `legacy` 区，不建立第二套颜色、尺度或排版 Token。[历史 DESIGN.md](../../DESIGN.md)、Phase 1 契约和 RC1 文档原样保留；本说明仅更新 RC2 候选的组件组织和呈现规则。

完整业务页面、正式写入、MCP、摄像头、上传、打印设备与生产入口仍属于后续阶段。完整回归继续暂停。代码实现、代理审阅、类型或构建结果都不能自动把 75 项更新为已批准；批准须来自用户明确反馈，并记录在既有审阅机制中。

收尾修正：管理摘要保留静态短编号以区分同名物品，完整编号仍在详情中；完成日期格式错误常驻显示；`OperationSheet.recoveryContent` 将只读恢复入口放在禁用编辑区之外，忙碌或上下文失效时隐藏。

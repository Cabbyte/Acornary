## 页面状态与数据边界

每页登记 9 个场景：正常、分页样例、空/不可用、读取中、失败可重试、无权限、离线部分缓存、离线无缓存、身份变化。共 36 个页面场景可打开，登记不等于全部执行验收。

- 正式页面只接收 `ItemView`、`GroupView`、数量 decimal string、保留类型/来源/依据的日期事实，以及受控查询与意图回调。
- 本轮适配器、11 件物品和零库存商品、合计计算、重试恢复均在 `apps/web/review/pages/`。这些数据与逻辑不得作为正式读取或业务成功实现。
- 正式页只拿一页数据与明确的分页元信息。通常按 50 条；专门的“分页样例”将样例页大小设为 5，以便审阅翻页。不推断服务端总数，离线样例显示总数未知。
- 搜索框仅提供名称查询；位置通过明确的容器范围筛选选择并标为“含下级”。完整位置全文搜索和任意查询组合未假装实现。
- 页面内可导航、筛选、翻页、展开日期依据与历史；添加、使用、移动等任务及管理页尚未装配，导航不可用分支不会产生假成功。
- 档案笔记与历史目前只读。附件、属性精确编辑、恢复控制器和全部写入流程留在后续批次。跨家庭、服务端权限与真实缓存隔离尚无集成证据。
- 页面路由由隔离 TanStack Router 适配器驱动。6007 使用 hash 表达页面路径，外层 query 表达审阅控件，工作台 `route` 参数记录当前页面以支持刷新/独立打开；Storybook 使用独立内存路由，避免 stories 互相污染。正式 `/manage/...`、旧深链与 QR 兼容接线属于 Phase 3。
- 模式开关在此批日常页禁用，配色仍有四套。主题预览不是管理业务页面；旧组件审阅继续支持两种模式。

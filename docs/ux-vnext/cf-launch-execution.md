## L1 第二批：管理、账号、持久化及路由

- 管理 25 类受支持任务采用共享命令构造与根会话，包括目录、库存策略、位置、处置/拆包、作废恢复、模板及重新归类。名称纠错不能冒充 `correct_item`；缺少明确引用绑定的分支保留输入并说明限制。
- 目录编辑与目录移动保持独立命令，治理引用绑定冻结命令。改名和祖先移动按 UUID 父子图更新派生路径；同名对象、含分隔符的名称不作为身份。仅派生资料变化不会增加后代 Item revision 或伪造其事件。
- 导出使用独立 `begin_export/read_export/cancel_export` 端口与原冻结元数据/游标。缺页、错误范围、非对象行或未确认取消不能报成功。初次冻结回执丢失时，契约没有原请求 lookup，保留旧记录并说明限制。当前适配器仍是隔离本地冻结样例，尚未连接服务端导出。
- 设置使用真实平等成员模型；移除虚构角色和移除他人操作。家庭改名、邀请撤销、通行密钥改名/移除及移除密码有独立类型化控制器。账号协议没有客户端幂等键，未知 POST 只做当前状态核对，不自动重放，也不把目标状态一致当成收到原回执。
- 非敏感改名输入归根任务保存；密码、邀请令牌和 WebAuthn 数据不写入通用任务日志。旧版设置样例原文保留，不能安全解释时阻止覆盖。邀请创建/加入、离开家庭、密码设置、WebAuthn/恢复/OAuth 真实适配仍待完成。
- 新任务持久化通过独立 IndexedDB 命名空间保存，绑定环境/origin、账号、家庭、客户端、稳定数据集；重登录代次不改变持久身份。写前 CAS、事务完成、精确回读均成功才确认保存；另一个窗口或畸形原记录不会被覆盖。作用域在异步开始前捕获，迟到结果不能进入新账号/家庭。

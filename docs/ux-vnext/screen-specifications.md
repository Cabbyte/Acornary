# 页面规格、线框与响应式

本文件是交互线框，不是生产界面或视觉截图。线框中的牛奶、件数和日期均为虚构设计样本，不读取或修改正式家庭。最终组件须使用真实领域类型；设计样本只能进入 Phase 2 的隔离 fixture。

## 布局系统

以应用根容器宽度 W 为准，不能以桌面窗口宽度替代 MCP iframe 内容宽度。读页面高度随内容，只有列表或面板需要时局部滚动；不同时套三层滚动容器。

| 条件                      | Shell / 内容                                             | 详情与任务                                      | 导航和触摸                                      |
| ------------------------- | -------------------------------------------------------- | ----------------------------------------------- | ----------------------------------------------- |
| W < 768（360/390）        | 单栏，左右16；工具栏可换行，搜索独占一行                 | 单件详情整页；操作全屏Sheet，头尾可见、中间滚动 | 顶部文字模式入口，底栏；主要目标44×44，输入16px |
| 768 ≤ W < 1024            | 紧凑shell，无常驻侧栏；页面最大960                       | 详情整页；宽度允许时560右Sheet，否则全屏        | 顶部导航按钮和文字模式入口；不塞图标侧栏        |
| W ≥ 1024                  | 216px侧栏 + 24px页面边距；日常内容最大1120；管理最大1600 | 单件可整页；管理内容可用宽度≥1160时列表+360详情 | 底部文字模式切换常驻；桌面控件36，触控仍44      |
| 管理目录/位置内容宽度≥960 | 240树 + 24间距 + 至少696结果                             | 详情另开页/Sheet；不强求第三栏                  | 不足960树变“选择分类/位置”面板                  |
| 1920宽屏                  | 内容仍限制最大宽，空白为阅读边距                         | 表格可增列，不拉长文字行                        | 模式与主动作仍在可预测位置                      |

管理表格可由“显示列”打开局部横向滚动，但姓名、选中状态、主要事实和动作在默认列宽内可用；整页不得横向滚动。手机直接改为摘要行，更多列在单件展开区，数据与选择状态不变。缩放到400%后的有效320px仍能重排，不硬编码卡片高度裁文。

同一视口内“添加物品”只出现一个主要入口：宽屏侧栏，窄屏页头；目录中的“新建商品资料”是不同任务，不混用。

A 标题只给当前查询可靠计数，不给“全家概况”假总数。B 首页不经导航即可输入，扫码具有文字名称。C 已应用筛选可单个移除，详细筛选面板只有位置/分类/状态/日期及现约排序；关闭未应用筛选不改变结果。D 物品主标题是链接，快捷操作是独立按钮；不嵌套按钮。能力不足时“使用”不作为可点击假入口；可通过详情理解未记录事实。E 加载更多是明确分页；已加载页与查询总数分别表示。

## S03 商品摘要

顺序：返回上下文 → 商品名称/规格/分类路径 → 服务器统计（当前件数、位置数、已知合计与未知件数）→ “再添这款” → 逐件分页列表。单件组直接一条 Item 行；不展示重复组头。商品属性修改只提供“管理商品资料”入口，切换模式时保留同一个 SKU。

合计示例“已记录 800g，另2件余量未知”，不写“总共800g”。不同单位分列；percent 不求和。统计暂不可读时占位“统计待更新”，不使用当前分页重算。0件可再次入库；不存在/不可访问显示非泄露错误与返回。

## S04 / S12 单件档案

```text
┌───────────────────────────────────────────────────────────┐
│ [返回搜索结果]                        日常 / 管理          │
│ 牛奶 · 自定义名称（若记录）       标签7a2c10     [更多]    │
│ 商品：品牌/规格    位置：厨房 / 冰箱 / 冷藏层               │
│ 剩余310mL（估计）   使用期限11月12日   开封：未记录         │
│ [记录使用] [移动]                     [补充资料]          │
│ 概览 | 笔记 | 历史                    管理：另有完整资料   │
│ 日期事实：类型、来源、依据，可展开多条                      │
│ 笔记：如何使用 / 这件的故事                     [写笔记]   │
│ 附件：能力允许时显示元数据与私有读取入口                    │
│ 最近变化：谁、何时、具体变化                  [查看全部]  │
│ [记录信息：完整身份、revision、模板版本]                    │
└───────────────────────────────────────────────────────────┘
```

日常首屏：身份/位置、最多3项适用关键事实、一个主动作（有余量能力优先使用，否则移动/查看资料）和移动次动作；未知但任务必要的量明确显示“未记录”。不为设备放一个空“过期”指标。完整属性按需展开，不要求用户进入编辑才能查看。

管理首屏：同一身份和事实；完整资料区按模板分组、显示版本/继承/覆盖、修改范围，更多列可读。当前 scope 在每个编辑入口重复明确为“此件”或“商品共有”。共享笔记/附件不和单件合并写。

手机详情是页面而非嵌套抽屉；打开动作时才加一个模态Sheet。返回优先原搜索/留意/位置/管理选择列表；直接深链接则回该模式物品页。页面标题获得焦点，不自动聚焦输入弹键盘。

## S05 需要留意

标题“需要留意”，下面为日期 / 补货 / 借出 / 维护类别选择，手机可换行或Select，不横向隐藏关键入口。日期区有“已过记录日 / 今天 / 未来7天”的清楚范围；卡片/行分别带日期类型。每行有明确对象和处理入口，补货行是商品，以“再添这款”为主动作。

同件多条日期显示主条及“另有 N 条日期”，N 必须来自已读取详情；只加载 next_date 时不编造 N。默认日期不含已完成 deadline；完成后可在详情/历史查看。无已知事项与未能读取采用不同空态。

## S06 / S17 操作面板

已有商品入库线框：

```text
┌──────────────────────────────────┐
│ 添加物品                   [关闭]│
│ 当前家庭 · 草稿已保存14:32        │
│ 商品 [已选择 牛奶 1L            ▾]│
│ 入库件数 [－] 1 [＋]             │
│ 存放位置 [未指定位置            ▾]│
│ [补充日期、开封、余量]           │
│ [逐件不同]       [再加一种商品]   │
│ ──────────────────────────────── │
│ 核对：牛奶 1L，1件，未指定位置   │
│ 日期、开封、余量未记录           │
│ [保留并关闭]       [确认入库1件] │
└──────────────────────────────────┘
```

读到当前上下文后才捕获原始 revision。未知字段收起，但摘要明确不会写入什么事实。填写了的可选字段自动保持展开；错误区始终可见。成功不是自动消失的 Toast：展示回执，允许完成后回原入口。

新商品 S06 显示四步标题：商品 → 分类 → 实物 → 核对。分类和批准范围可展开；缺契约分支有明确“等待支持”状态及保留草稿按钮，不能可点击提交。所有步骤属于同一任务。

消耗/移动线框：

```text
记录使用                         移动物品（3件）
牛奶 · 标签7a2c10 · 冷藏层        查看所选3件（含1件不在当前列表）
当前310mL（估计）                 原：冷藏层/储藏柜
[用掉一部分] [整件用完]          目标 [搜索位置与完整路径______]
本次 [50] mL  依据 [未记录]      仅有效容器；自身/下级显示原因
预览：预计剩260mL                预览：3件 → 厨房 / 储藏柜
[保留并关闭] [确认记录]          [保留并关闭] [确认移动3件]
```

普通面板宽560、复杂批量/三方对比宽720（不得超过内容宽减32）；手机全屏。选择器在同一面板内切子步骤，返回回该字段；审批/冲突作为同级步骤，不用三层模态堆叠。危险操作按钮带具体对象数与含义，最终摘要不可折叠。

## S07 / S13 动态与历史

日常：时间范围（默认最近7个家庭自然日，可改）→ 按记录日分组的操作摘要 → 受影响对象入口 → 加载更多。管理：增加事件类型/对象/operation筛选，展开前后值、来源、技术信息、纠正入口。两者读同一 HistoryView，排序/分页保持服务端语义。

一个原子批次的多条事件以操作组展示，未完整加载必须标“部分”；“查看本次全部变化”按 operation_id 读取。没有权限读取的对象用“对象不可访问”，不能借历史还原隐私。失败/空/离线带范围和更新时刻。

## S08 扫码 / 标签

布局：返回 → “扫描物品标签或商品条码” → 相机能力区域（需点击启用）→ 可随时切手动输入 → 识别类型和候选 → 下一步。一次识别暂停摄像，避免重复弹详情；继续扫描显式恢复。未识别保留文本，不能自动把任意URL当可执行路由。

标签子面板：选中实物清单 → 当前纸型及设备 → 单张/多张预览 → “开始打印 N 张” → 逐张状态。打印时关闭代表“停止后续”，当前张结果单独确认；说明已发送无法撤回。无支持设备显示原因与可行外部入口。

默认列：选择、名称/商品识别、位置、关键数量/日期事实、记录状态、更多。可选列为已知模板/版本/更新时间等；切列不改查询语义。名称/日期/创建/更新时间的排序仅按真实支持项提供；不把当前页局部排序称全量排序。选中范围固定显示，不在滚动后消失。

手机上已选数量和“查看所选”在主工具栏下，动作收为“批量操作”；操作面板先列范围，再选命令。筛选和选择互不覆盖。100件上限、隐藏选择、混合能力和原子性见 M04。

## S10 / S11 两个独立结构工作台

```text
商品目录                                   位置与容器
┌分类 GROUP 树───┬商品 SKU 列表────────┐   ┌位置 Item 树─┬容器内容────────┐
│食品            │商品/类型/规格/款资料 │   │家            │房间/箱/抽屉身份 │
│ └乳品          │完整分类路径         │   │ └厨房        │当前物理路径     │
│服饰            │[新建商品] [新分类]  │   │   └冰箱      │可容纳/内容范围  │
│                │[编辑共享] [归类移动]│   │              │[新建位置][移动] │
└────────────────┴─────────────────────┘   └──────────────┴─────────────────┘
```

目录移动预览分类路径；容器移动预览物理路径，词汇、图标和面板标题区分。点击树行选择，展开箭头独立。键盘方向键/Home/End 管树；搜索结果也显示完整路径。空分支提示可建什么，不能点空白默认创建。

目录详情保存是商品/分类命令，容器详情保存是 Item 命令。不存在的/作废目标不自动跳到同名记录。未知层级先显示“正在读取路径”，不能短暂显示根级误导。

## S14–S16 设置、身份与检查器

S14 单列最大720，设置项有名称、当前值/状态与可操作箭头；不会因库存读取失败挡住退出/重新授权。账号、家庭、打印分别为既有子路由。缓存页显示读缓存和待恢复任务两类状态。

S15 表单独立认证布局，品牌与目标任务可见；保留 Passkey 优先、密码备用、服务端允许的注册/恢复/邀请。OAuth consent 的服务、家庭、权限和允许/拒绝是不可隐藏内容。失效邀请、密码错误、Passkey取消、邮件等待/失败都有就地下一步，不替用户确认授权。

S16 是高级只读检查，不承担日常管理。保留原查询范围、原始字段与脱敏规则；需要写入时链接到实际业务任务。它也在 Ant 移除清单中，不能留在旧主题下宣布全迁移。

## 内容和交互下限

长名称允许2行后展开完整内容，tooltip不是唯一读法；路径可折叠中间节点但打开选择器/核对时必须完整。列表日期首见显示年份，避免跨年误解；详情显示完整日期和类型。缺图片用现有Lucide分类图标，不伪造实物照片。数量/单位同一可读组，保持十进制字符串精度。

读空态有明确原因与一个主要下一步；失败保持查询/草稿；加载替换相同几何区域，不清屏闪烁。所有“更多”菜单必须由适用操作构建，不放未实现按钮占位。无权写可见事实仍能读，不能用整页disabled遮盖信息。

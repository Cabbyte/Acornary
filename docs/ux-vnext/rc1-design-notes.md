# 松仓 · Acornary RC1 设计候选说明

## Overview

本说明记录 Component Library RC1 的实际源码与交付边界，适用于隔离预览中的 **70 个组件和 5 个组合场景**。全部 75 项仍为“待审阅”；四套配色及可切换方案已有确认记录，正式默认配色、组件视觉与交互仍待用户审阅。预览初始值 `sage / daily` 仅用于预览。

当前候选以浅色背景、白色内容面、系统无衬线字体和少量强调色组织信息。日常与管理模式共享组件、事实表达和状态语义，通过强调色、内容宽度及列表密度体现差别。描述以可见实现为限，不另设品牌隐喻。

唯一可编辑 Token 值源是 [source.json](../../apps/web/src/ui/tokens/source.json)。[生成 CSS](../../apps/web/src/ui/theme/tokens.generated.css)、[Token 文档快照](design-tokens.json)与[色对记录](token-contrast.md)均由它派生；本文只解释用途，不另存颜色值或建立第二套 Token 定义，也不生成独立设计侧车。

[根目录 DESIGN.md](../../DESIGN.md)和 [PRODUCT.md](../../PRODUCT.md)保留旧版实现记录；其中宋体标题、旧标题尺度与暖纸色面，以及 [Phase 1 组件契约](component-contracts.md)中的宋体、日常正文 16px、旧行高，**仅在 RC1 候选范围内由本轮契约与源码覆盖**。旧版实现和 `source.json` 的 `legacy` 区保持不变。未知事实、实物身份、日期语义和明确操作范围等产品约束继续成立。

交付状态见 [RC1 报告](rc1-report.md)，审阅记录见 [review-status.json](../../apps/web/review/review-status.json)。本轮已完成限定前端 TypeScript、预览与 Storybook 构建、Token 派生与 125 组指定不透明色对、静态导入边界及 70＋5 目录检查；591 个场景登记通过目录检查，不代表逐项浏览器验收。代表性交互已检查主题／宽度切换保留输入、管理表格跨页后的隐藏选择、390px Sheet 全高显示及 Escape／焦点返回、操作忙碌关闭守卫与结果未知时保留任务。独立只读审阅结论支持按此范围交付候选，未确认需要立即修复的实质问题。

这些证据不包含完整测试与回归套件、真机或真实 MCP 宿主、性能基准、完整键盘／读屏／多浏览器可访问性验收。正式业务页面、库存写入、审批、持久化恢复、摄像头、上传和打印设备均未接线。

## Colors

配色由 `preset × mode` 组合选择，8 个组合均保持浅色。下列名称沿用 Token 源，不另创造色名：

| 方案 | 日常模式强调 | 管理模式强调 |
| --- | --- | --- |
| `sage` · 苔绿与石板蓝 | 苔绿 | 石板蓝 |
| `apricot` · 杏橙与靛蓝 | 杏橙 | 靛蓝 |
| `berry` · 莓紫与青灰 | 莓紫 | 青灰 |
| `terracotta` · 陶土与蓝灰 | 陶土 | 蓝灰 |

`accent` 用于主动作；`accent-text` 用于轻量文字动作；`selection` 与 `selection-foreground` 配对表示选择。Hover、Active 和选择文字色在生成阶段确定，组件直接消费生成变量。

`background` 承载浅色底，`surface` 与 `surface-raised` 承载白色内容面；`foreground`、`muted-foreground` 分别用于主要文字与补充说明。`border` 分隔内容，`control-border` 标识可操作控件边界，不用细分隔线代替输入边界。

危险、警告、成功、信息、焦点和禁用角色由公共语义 Token 提供，不随配色方案改义。语义色同时配有文字、图标或状态标签；错误与未确认结果不能只依赖颜色识别。指定色对检查仅覆盖其记录的组合和阈值，透明度、叠层与全部交互状态仍需实际验收。

## Typography

标题与正文共享系统无衬线字体栈，实际字体栈以 Token 源为准；没有引入远程字体。RC1 不沿用旧版宋体标题。

| 角色 | 当前尺度与用途 |
| --- | --- |
| 面板／页面标题 | 22px，行高 1.3；窄屏仍为 22px |
| 分区／商品摘要标题 | 16px，主要使用 600 字重 |
| 桌面正文与常规控件 | 日常、管理均为 14px，正文行高 1.5 |
| 窄容器正文与输入 | 16px；粗指针输入也采用触屏尺度 |
| 元信息与辅助说明 | 13px；明确的辅助层级保留自己的字号 |

字重使用 400／500／600 区分正文、控件与标题。数量使用等宽数字，保留传入的十进制字符串、单位和“约／精度未记录”等说明。长名称、标签、位置和提示允许换行，不以截断掩盖关键事实。

## Layout

布局受可用容器宽度约束。[主题根样式](../../apps/web/src/ui/theme/vnext.css)在容器小于 768px 时启用窄屏字号与触达尺度；常规桌面控件最小高度为 36px，窄容器与粗指针主控件至少 44px，关闭和返回目标始终为 44px。

间距沿用 4／8／12／16／24／32／48px 尺度。列表面板通常采用 16px 内边距与间隔，Shell 主区桌面采用 24px、窄屏采用 16px。日常列表基准最小行高为 64px，管理桌面为 48px；当前物品行与管理表格在窄屏或粗指针条件下扩为至少 72px，内容增长时继续增高。

当前 [AppShell](../../apps/web/src/ui/patterns/app-shell.tsx)提供侧栏、顶部家庭与配色入口、主区及窄屏底部导航。侧栏宽 216px；日常内容最大宽度为 1120px，管理为 1600px。Shell 自身容器小于 768px 时隐藏侧栏并重排导航区域。Token 中其他侧栏、位置树、并列详情阈值仍需未来正式页面按实际装配验证，不能据此宣称完整页面已实现。

Sheet 桌面靠右，常规宽 560px，宽版 720px；窄容器使用全宽、全高 `100dvh`。头尾保留，内容区独立滚动。宽度和主题切换由 CSS 与受控属性改变表现，保留同一子组件树和表单实例；浮层放入 [ThemeProvider](../../apps/web/src/ui/theme/provider.tsx)提供的容器，继承当前主题与所在文档的焦点环境。

## Elevation & Depth

内容面主要通过背景、白色面板、细线和间距分层。弹层具有明确深度：[浮层样式](../../apps/web/src/ui/components/ui/overlays.css)为 Dialog／Sheet 提供遮罩与较大柔和阴影，为 Popover／菜单、Tooltip、Toast 提供较轻阴影。阴影从现有前景色混合透明度生成，当前没有独立可编辑阴影 Token，不把这些局部值另立为新规范。

常规状态过渡使用 120ms，面板过渡使用 180ms；减少动态效果偏好将 Token 时长归零，相关旋转／脉冲动画停止。动效只辅助状态与层级变化，不代替等待、错误和结果不确定的文字说明。

## Shapes

控件、状态标签和轻量选择面使用 8px 圆角；列表面板、物品行／卡片及浮层使用 12px 圆角。桌面 Sheet 仅保留靠内容一侧圆角，窄屏全高 Sheet 去掉圆角与外边框。普通控件和面板使用细边框，焦点轮廓为 2px、偏移 2px；具体组件可在边界内调整轮廓位置以保持可见。

## Components

基础控件位于 [components/ui](../../apps/web/src/ui/components/ui)，领域展示位于 [patterns](../../apps/web/src/ui/patterns)。候选采用 shadcn 的 Base UI 组合模式与 Base UI 行为原语，日期、表格分别使用现有 DayPicker、TanStack Table；旧版 Ant Design 入口保持原状。

| 代表组件 | 当前形态与行为 |
| --- | --- |
| Button／IconButton | 主按钮使用强调实底；次按钮为白面与控件边框；quiet 使用文字强调；danger 使用危险语义。忙碌态保留标签并禁用重复操作，图标按钮需可读名称。 |
| Input／FormField／选择控件 | 白面、可辨认边界与统一焦点轮廓；字段标签、帮助与错误信息相邻。只读、禁用、无效和加载状态分别表达。 |
| Badge／InlineNotice | 标签紧凑，通知在正文附近解释状态与可用动作；品牌强调不覆盖警告、错误或结果未知的语义。 |
| ItemRow／ItemCard／ProductSummary | 行与卡共享实物身份、事实和意图接口；摘要明确读取范围、已知数量和未记录数量。商品分组不代替具体实物操作目标。 |
| DataTable／BatchSelectionBar | 外部控制排序、筛选和分页；选择以完整稳定 ID 保存。“选择本页”只改变已加载且可选记录，隐藏选择与实际范围继续可见；100 件批量上限不隐式拆批。 |
| Dialog／Sheet | 共用受控开闭与关闭守卫，Escape、关闭按钮等关闭意图经过同一判断；支持初始与返回焦点。关闭受阻时给出原因。 |
| OperationSheet／恢复提示 | 核对中与提交中阻止关闭；结果未知时显示“保留任务并收起”并调用保留意图。身份／家庭变化时隐藏旧任务内容。回调表达意图，持久化和真实执行由后续业务层负责。 |
| AppShell／Navigation／模式与配色选择 | 导航、家庭、模式与主题由调用方控制。模式变化不重建业务内容，切换阻断原因可读；当前导航使用 `aria-current`。 |

数量未知保持“未记录”，零仍是已知值；日期保留用途、日期类型、来源与依据，不从浏览器时区推导家庭事实。扫码、附件与打印控件呈现传入的能力状态，不以演示回调声称设备操作成功。

五个[隔离组合](../../apps/web/review/groups/compositions-demos.tsx)分别展示搜索与物品列表、小型物品表单、操作与恢复、管理选择、双模式 Shell。它们共用组件源码，以本地 fixture 与场景驱动检查组合关系；完整业务页面装配在用户组件审阅后另行进行。

## Do's and Don'ts

- **Do** 从唯一 Token 源修改值并重新生成派生物；候选样式保持在 vnext 范围内。
- **Do** 同时检查配色、日常／管理模式、窄容器、粗指针、焦点及长文本，保留输入和当前任务上下文。
- **Do** 保留未知、零、估计、缓存子集、隐藏选择和结果不确定的区别，以说明与可用动作帮助判断。
- **Do** 通过明确反馈与批准记录推进每项审阅；当前 75 项继续标为待审阅。
- **Don't** 将 `sage / daily` 预览初始值写成正式默认方案，或把构建、目录与色对通过写成用户批准。
- **Don't** 将旧版宋体／字号规则重新套入 RC1，或借本说明改写 legacy 与正式入口。
- **Don't** 因切换主题、模式、宽度或收起面板而丢弃草稿、选择或结果待确认的原任务。
- **Don't** 将演示状态、代表性浏览器检查或源码行为描述扩展为完整回归、无障碍、真机、MCP、设备或生产验收结论。

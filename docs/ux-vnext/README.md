本批把日常浏览链路装配为正式 React 页面，以受控 props 接收事实和意图回调。隔离适配器提供查询、分页与路由演示，正式 Web/MCP 入口未变。修改意见跟随当前页面，并记录具体对象和查询路由。组件、组合示例与业务页面各自保留版本和审阅状态。

四套浅色配色通过同一 Token 系统切换，内容面保持白色；字体、尺度、控件与页面视觉仍可分别提出修改。当前默认 `sage / daily` 仅用于预览。制作顺序已调整为一次完成全部候选后统一审阅，覆盖旧的逐批等待规则。

RC6 延续 Operate（操作优先）的默认画面：突出名称、关键事实、影响范围和主动作；宽屏列表及表单利用横向空间，来源和普通帮助按需展开，物品编号可直接复制。未知、估计、审批影响、冲突与结果待确认仍可查看。审阅说明在产品画布之外，预览统一标明“预览 · 示例数据”。同一组件不因切换模式改变字号或行高；管理表格仍按自身结构保持适合的信息密度。

## 设计结构

| 日常：找到并处理具体物品                            | 管理：维护事实与结构                                  | 两者共享                                               |
| --------------------------------------------------- | ----------------------------------------------------- | ------------------------------------------------------ |
| 我的物品、需要留意、最近变化、设置                  | 物品管理、商品目录、位置与容器、动态与历史、设置      | 搜索、单件身份、任务状态机、领域命令、授权、家庭作用域 |
| 首页搜索；明确单件的“使用/移动”；添加是常驻任务入口 | UUID 明细、两个独立树、批量范围、模板与版本、影响预览 | 同一个 OperationSession，不因模式和视口变化重建        |
| 四套浅色配色的日常强调色，较大触控区域              | 对应管理强调色，较高信息密度                          | 白色内容面、状态色、字体、间距与焦点规则               |

添加不占底部导航位置。手机日常底栏为“物品 / 留意 / 动态 / 设置”；管理底栏为“物品 / 目录 / 位置 / 动态 / 设置”。模式入口在手机顶部、桌面侧栏底部。

## 重要边界

- 基础原子入库、明确 UUID 的消耗/移动、草稿和审批协议已有基础；必须复用语义，不能重写成模拟业务。
- 新商品原子入库目前不能声明商品 profile/capabilities。基础新商品仍能原子入库；显式新类型及能力这一分支是 G01 集成门槛，不以先建商品再补库存冒充原子流程。
- 任意模板批量编辑、任意自然语言搜索、通用“撤销”、跨客户端草稿同步都没有在本稿中被承诺为现有能力。
- MCP 当前过滤 stock/void/split/references/attachments，Web 有接口不代表宿主可用。限制适配器须保留；完整迁移不能以隐藏现有 Web 能力交差。
- 颜色计算、设计线框、代码阅读和既有 CI 均不等于真实用户或真实 MCP/打印设备验收。

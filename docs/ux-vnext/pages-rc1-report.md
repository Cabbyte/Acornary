## 共享边界

正式页面接收受控事实与用户意图；审阅适配器和 fixture 位于 review/pages。P03 的入库、消耗、移动通过共享隔离库存快照更新列表、详情和动态，并按原请求键返回同一示例回执。快照仅使用审阅专属 sessionStorage；不读取或迁移正式草稿，不代表生产恢复协议已经验收。

管理模式由 URL 决定，设置保留 mode 参数；模式切换共享界面体系，不更改权限。逐页意见绑定当前路径、版本和场景。服务、认证、上传、扫码和打印能力均为预览状态，不执行正式业务或真实设备命令。

## 已知预览边界

- 设置内家庭、权限和认证使用独立内存样例，跨设置子路由保留、整页刷新重置；切换家庭不会更换其他页面的示例库存。
- 管理的目录与模板覆盖层独立于正式查询；公共单件修改同步示例库存与历史，但完整目录/属性投影仍须在真实接线时统一。
- 开封、包装日期、单件笔记可反馈到档案；其他日期事项、附件及设备状态由日常补充适配器保留，不代表后端持久化已经完成。
- 所有操作状态为隔离控制器候选，尚未完成共享正式 OperationSession、全局提交关闭守卫、身份切换隔离、幂等与真实审批的工程验收。
- 不支持的关联写入、能力契约或宿主功能保留解释与禁用分支；不以 UI 成功表示真实服务能力。

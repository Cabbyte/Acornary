# P03-RC1 日常任务审阅候选

2026-11-09。四个新任务均待用户审阅，未自动批准 P02 或本批页面。

## 内容与入口

- 已有商品入库：商品选择、默认 1 件、1–100 件校验、明确位置、逐件最佳食用期、核对和逐件示例 ID。
- 新商品入库：名称查重提示、复用已有商品入口、完整分类路径、审批范围、实物信息和原子结果展示。类型/能力契约缺口场景阻止提交并保留草稿。
- 使用：明确 Item UUID、部分或整件、十进制数量、超量阻止、依据未知/估计/实测、剩余量计算预览。
- 移动：明确 Item、有效容器候选或移出容器、前后位置、核对。

工作台稳定入口：`page-daily-intake`、`page-daily-new-product`、`page-daily-consume`、`page-daily-move`，版本 P03-RC1。我的物品“添加”、列表使用图标及移动、商品“再添这款”、单件档案操作已相连。关闭任务后可填写逐页修改意见，版本与路由自动随任务变化。

正式组件 `daily-task.tsx` 只接收受控数据和回调。`review/pages/TaskJourney.tsx` 是隔离预览适配器，保存独立 sessionStorage 草稿、原请求标识和快照；没有正式业务调用。提交前存储失败禁止发送，提交中阻止面板关闭，结果不确定可保留并离开；刷新恢复原标识。开始新样例仅清理当前预览任务状态。

## 验证与限制

前端 TypeScript、独立预览/Storybook 构建和静态边界已执行。正式入口 77 文件无 fixture 引用；候选 UI 84 文件无业务/设备 I/O。保留原开发包体积与配置扩展名警告。

浏览器人工检查了部分使用→核对→提交守卫→示例结果，以及不确定结果刷新后原请求标识与输入保留、核对原请求；工作台四个入口可达。未执行四流程所有分支、全部尺寸、读屏或完整键盘验收。

这是交互候选，不是正式 OperationSession 或命令协议集成。目录审批、版本变化和回执由预览适配器明确模拟。当前冲突样例对比版本与原输入，不替代正式逐字段冲突解析。入库日期只开放包装最佳食用期，其余日期类型在 P04 装配；批量容器/后代重叠移动留管理批次。新建/使用/移动结果只显示任务结果，不修改只读浏览 fixture；正式库存和统计刷新待接线。sessionStorage 不提供跨标签或关闭浏览器后的恢复保证；正式持久化恢复与身份隔离仍是工程验收前置项。

回归继续暂停：未运行 Vitest、Playwright 回归、Docker CI、真实 MCP/设备、性能或生产写入验收。未改正式库存、正式入口、依赖或部署；不推送、不部署。

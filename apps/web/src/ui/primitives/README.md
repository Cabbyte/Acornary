# Acornary primitives

The design-system layer between `tokens.ts` / `tokens.css` and the pages.

## Rule

**Pages use primitives, not Ant Design directly.**

- Ant imports are allowed only inside `Button.tsx` and `Sheet.tsx`, where Ant supplies behavior.
- Every other primitive is plain HTML + CSS Modules.
- Variants and tones are finite enums mapped to `data-*` attributes and CSS variables.
- Primitives are presentational: no data fetching, stores, business logic, or feature imports.
- Pages may pass `className` for layout positioning only; never for visual customization.

`index.ts` imports `tokens.css` once, so importing from `./index.js` is enough. If you import a
single module directly, import `../tokens.css` yourself. Primitives never hardcode colors; they
read the `--ac-*` variables generated by `tokens.ts`.

## Imports

```tsx
import {
  Button,
  EmptyState,
  FactChip,
  Field,
  IconButton,
  ItemRow,
  Metric,
  PageHeader,
  Section,
  Sheet,
  StatusTag,
  Toolbar,
} from '../../ui/primitives/index.js';
```

## Button

```tsx
<Button variant="primary" onClick={save}>记录消耗</Button>
<Button variant="secondary" icon={<ArrowRightOutlined />}>移到位置</Button>
<Button variant="quiet" size="sm">取消</Button>
<Button variant="danger" loading={removing}>整件用完</Button>
```

- `variant`: `primary | secondary | quiet | danger` (maps to Ant's visual type internally).
- `size`: `md` (36px desktop / 44px mobile) or `sm` (28px).
- `type` is the native button type; `htmlType` overrides it for Ant if ever needed.
- One `primary` per screen. Destructive actions use `danger` plus a confirmation.

## IconButton

```tsx
<IconButton
  label="牛奶 1 L 的更多操作"
  title="更多操作"
  icon={<MoreOutlined />}
  aria-haspopup="menu"
  onClick={openMenu}
/>
```

`label` is required and becomes `aria-label`. `title` is an optional native tooltip. The target is
36×36 on desktop and 44×44 on phones/coarse pointers.

## StatusTag + FactChip + Metric

```tsx
<StatusTag tone="warning">临期 3 天</StatusTag>
<FactChip>剩 1 L</FactChip>
<Metric label="剩余" value="1 L" hint="开封 3 天" />
```

`StatusTag` always renders visible text next to the decorative dot, so state is never color-only.
`FactChip` is text only and has no button behavior. `Metric` values use tabular numerals.

## PageHeader

```tsx
<PageHeader
  back={{ label: '我的物品', onClick: () => navigate({ to: '/' }) }}
  title="牛奶"
  subtitle="厨房 / 冰箱 / 冷藏层"
  actions={<Button variant="primary">记录消耗</Button>}
/>
```

`back` accepts either `{ label, onClick }` or `{ label, href }`. The back target is at least 44px.
The component renders exactly one `h1`.

## Toolbar

```tsx
<Toolbar
  search={<Input.Search placeholder="搜索物品" aria-label="搜索物品" />}
  actions={
    <Button variant="primary" icon={<PlusOutlined />}>
      添加
    </Button>
  }
>
  <Button variant="secondary">筛选 2</Button>
  <Button variant="quiet">排序</Button>
</Toolbar>
```

The toolbar uses a container query: under a 720px container the search becomes a full row and the
actions wrap beneath it. It adapts inside MCP iframes and detail panels, not just the viewport.

## ItemRow

```tsx
<ul className={styles.list}>
  {items.map((item) => (
    <li key={item.id}>
      <ItemRow
        title={item.name}
        thumbnail={item.photo ? <img src={item.photo} alt="" /> : <CategoryIcon />}
        facts={['剩 1 L', '开封 3 天', '剩 60%']}
        location="厨房 / 冰箱 / 冷藏层"
        status={{ tone: 'warning', label: '临期 3 天' }}
        overflow={
          <IconButton label={`${item.name} 的更多操作`} title="更多操作" icon={<MoreOutlined />} />
        }
        onOpen={() => openItem(item.id)}
        selectionMode={selecting}
        selected={selectedIds.has(item.id)}
        onSelectedChange={(next) => toggleSelected(item.id, next)}
      />
    </li>
  ))}
</ul>
```

- Only the first three facts render.
- The checkbox column appears only with `selectionMode`.
- The whole row is a stretched native button, so Enter and Space open it without nesting the
  checkbox or overflow button inside an anchor.
- The generated `aria-label` reads name, location, and status only. Override it with `openLabel`.
- Never pass a raw id or UUID as the location or title.

## Section

```tsx
<Section
  title="资料"
  description="已记录 4 项"
  action={
    <Button variant="quiet" size="sm">
      补充资料
    </Button>
  }
  collapsible
>
  <p>品牌 蒙牛 · 规格 1 L · 购入 10 月 1 日</p>
</Section>
```

Collapsible sections use native `details`/`summary`. The action is a sibling of the summary, so
clicking it does not toggle the section.

## Sheet

```tsx
{
  sheetOpen && (
    <Sheet
      title="记录消耗"
      onClose={closeSheet}
      busy={saving}
      size="narrow"
      footer={
        <>
          <Button variant="quiet" onClick={closeSheet} disabled={saving}>
            取消
          </Button>
          <Button variant="primary" loading={saving} onClick={submit}>
            记录
          </Button>
        </>
      }
    >
      <Field label="数量" required error={errors.amount} hint="最多 1 L">
        <Input value={amount} onChange={(event) => setAmount(event.target.value)} />
      </Field>
    </Sheet>
  );
}
```

Render the Sheet only while it is open. It is a right drawer at 480px (`narrow`) or 560px (`wide`)
on desktop and full-screen on phones. Escape and mask clicks close it unless `busy`. Focus returns
to the opener on unmount; the close target is 44px.

## Field

```tsx
<Field label="到期日" hint="格式：2026-11-05" required error={error}>
  <Input value={expiry} onChange={(event) => setExpiry(event.target.value)} />
</Field>
```

`Field` clones its single child control to add `id`, `aria-describedby`, `aria-invalid`, and
`aria-required` / `required`. It owns no value or validation state.

## EmptyState

```tsx
<EmptyState
  icon={<BoxIcon />}
  title="这里还没有物品"
  description="添加第一件物品，之后会出现在这里。"
  action={<Button variant="primary">添加第一件</Button>}
/>
```

## Accessibility contract

- Focus ring: 2px `--ac-accent`, 2px offset on every interactive primitive.
- Mobile/coarse pointer targets: at least 44×44 for buttons, icon buttons, row checkboxes, sheet
  close, page-header back, and section summaries.
- No color-only state: status text, error text, and checkbox state are always available non-visually.
- Motion uses the 120–180ms token curve and collapses under `prefers-reduced-motion`.
- Every icon-only control requires a `label`; every Sheet has a visible title.

## Intentionally deferred

- No page wiring, AppShell, or data adapters in this batch.
- No dark theme; the tokens are light-only for now.
- No Storybook/`/ui` kitchen-sink page yet.
- `ItemRow` does not define the overflow menu itself; pass an `IconButton` or menu trigger.
